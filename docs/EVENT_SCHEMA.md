# Event and bridge contracts

The authoritative detailed event field list is [SCHEMA.md](../SCHEMA.md); strict executable rules are `tools/validate_export.py`. Schema `bookmap-orderflow-v0.1` remains unchanged despite addon software 0.5.0. Wire protocol `orderflow-live-v0.1` is a distinct envelope version.

Common fields: schema, positive contiguous seq beginning at 1, market_ns (signed-long-range integer, nonnegative; START may be zero), phase HISTORY/REALTIME, nonempty constant alias, event. MBO events also carry order_id, side BID/ASK/UNKNOWN, price_level, price, size and anomaly. Writer can preserve UNKNOWN/null/anomaly for missing references; strict complete-session validation rejects inconsistent MBO histories. Price = level × pips; pips is in the summary and bridge WELCOME. Trade price_level has API double type but validated ticks must be integral. Multiplier is instrument metadata, not an order quantity transform.

Trades additionally carry aggressor_side BUY/SELL, size, nullable aggressor_order_id/passive_order_id, execution_start, execution_end and otc. Zero-size execution-end boundary markers are preserved and recognized; they are not volume fills. IDs must never be discarded or coerced to an imprecise floating-point number. MBO updates alone mutate the book.

CONTROL has control and detail. START is first, REALTIME_START transitions phase once when present, STOP finalizes, TIME_REVERSAL preserves rewind evidence but makes strict research capture invalid. Time ties are valid; time reversals, missing/duplicate seq, duplicate adds and unknown replaces/cancels invalidate. Validator rejects unknown/extra event keys, duplicate JSON keys and nonfinite values. Capture-only validation cannot check pips or summary equivalence and explicitly reports that limitation.

Summary records version/configuration, counts received/enqueued/written, open orders, anomaly counters, writer status/error, buffer/checkpoint/I/O observations, callback histogram and optional bridge snapshot. `records_persisted` is a legacy logical writer counter: it advances after writing into BufferedWriter, not after fsync. Only a clean finalized summary plus archive validation establishes logical complete export; no power-loss durability is claimed.

An EVENT envelope has type EVENT, protocol, session, sent_epoch_ns, replay and event (the unchanged canonical object). WELCOME contains publisher health including alias/pips/session. Sender wall time is millisecond-resolution multiplied into nanoseconds; it is not exchange time and lag depends on clock synchronization. Receiver commands: `HELLO owner validated_seq` / `ACK owner validated_seq`. Health REQ payload HEALTH returns status without market registration. See [LINUX_BRIDGE.md](LINUX_BRIDGE.md) for failure/recovery semantics.
