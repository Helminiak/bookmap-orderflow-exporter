# Shutdown integrity regression checkpoint

Baseline: `cd5c09f825652a7b295d7794da111866aff95e9e` (production source identical to native-tested `03319fd`). The synthetic regression `ExporterShutdownTest.stopCannotOvertakeAnAcceptedCallbackBeforeQueueInsertion` fails against that source and passes with this lifecycle change. It pauses an actual MBO callback in the real buffer's `add`, after sequence reservation and before visibility to the writer. Old STOP overtakes it: START and STOP persist, the intervening accepted MBO event does not. This proves a sufficient failure path for the native signature; the native capture alone does not identify the original thread interleaving.

The candidate serializes callback admission, sequence reservation and enqueue with the STOP boundary. STOP seals admission under the same monitor before placing its terminal record. Writer draining occurs outside the monitor so post-boundary callbacks return without changing book state, counters or sequence. The writer also rejects noncontiguous sequence numbers, and finalization compares persisted count with allocated sequence. `total_records` reports actual written records; additive `last_allocated_seq` preserves attempted sequence evidence when invalid. Gzip close failures still invalidate the writer; a write or flush is not fsync.

Focused regression checks START / accepted MBO / STOP exactly once and in order, late callback rejection, idempotent stop, final order count and summary counts. Existing missing-receiver and summary-write-error shutdown tests pass. Full build/validator results are recorded in the master handoff after execution.

This is an intermediate reliability fix, not release acceptance. Historical network waits and strict journal backpressure can still hold the admission monitor; bounded callback and asynchronous lifecycle acceptance are pending. Bridge retention/STOP overflow, drain validity and receiver durability are separate work. Windows native acceptance, 125%/150% DPI, REALTIME and full-session soak remain unproved. Nothing was installed into or restarted in the active Bookmap workflow.
