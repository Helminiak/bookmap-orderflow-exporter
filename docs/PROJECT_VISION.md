# Product vision

Bookmap → Canonical MBO/Trade Events → Exporter/Bridge → Linux Processing → Historical Research / Private Entry Engine.

The public subsystem answers what Bookmap delivered, in which order and with what integrity evidence. It preserves acquisition semantics across historical extraction and LIVE transport. It does not make trading decisions.

The private long-term system evaluates ES entry quality at the hard right edge using information available at that instant. Its objective is entry-quality assessment, not general directional forecasting or trade-management optimization. Specific criteria, features, thresholds, labels, scoring, inference and execution remain private and are not described here.

Product success requires reproducible raw-data equivalence, responsive LIVE acquisition, explicit overload/failure signaling and clean public/private contracts before downstream research claims. Working connectivity is a milestone, not proof of strategy value or production readiness.
