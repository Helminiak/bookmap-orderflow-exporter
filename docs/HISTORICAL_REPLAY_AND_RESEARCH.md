# Historical replay and accelerated research roadmap

Goal: Bookmap decodes each licensed BMF once into validated Tier 1; training never depends on replaying at wall-clock speed. The public exporter is not a model-training runtime. PRIVATE PRs #2/#3 contain offline compilation/replay and causal dataset candidates; their merge/release acceptance is separate and no private feature/target formulas are specified here.

Proposed pipeline: BMF hash + extraction settings → canonical archive/summary hashes → strict integrity acceptance → compiled columns (event/side codes, integer tick coordinates with pips, sizes, lossless IDs, seq and market_ns) → deterministic book replay → causal research observations → separately governed future outcomes. Arrow IPC supports efficient sequential/memory-mapped columns; Parquet favors compression/partitioned analytical scans. Encoding IDs/dictionaries reduces repeated strings but must preserve exact IDs and nullable values. Schema/compiler versions and manifests make transforms auditable.

Event time is input data, not a sleep interval. Process sequential records as fast as computation/storage allows; virtual market-time windows and timers advance deterministically. Maintain order for each book: ADD/REPLACE/CANCEL dependencies forbid arbitrary reordering, and trades alone cannot reconstruct MBO. Parallelize independent complete sessions/aliases, not dependent events within a book. Starting arbitrary partitions midway requires a validated initial snapshot/checkpoint; no exporter bridge snapshot protocol currently exists.

Real throughput constraints are JSON parsing/decimal checks during compilation, decompression, column I/O, ID lookup/map churn, feature cost and worker memory. Existing synthetic acquisition throughput does not predict private feature throughput or simulated hours/s. Benchmark complete sessions with elapsed time, market duration, records/s, storage, RSS/heap and final-book equivalence. Avoid oversubscribing sessions that saturate disk/RAM; record hardware and repeated warm/cold trials.

Chronological train/validation/test separation must account for overlapping extractions, market-date aliases, lookback windows and future outcome horizons. Purge shared history/boundary overlap as required by the private research contract, fit transforms on training data only, and keep future outcomes out of live inputs. Deterministic replay equivalence, provider completeness and source provenance are prerequisites, not established by model score. Look-ahead safeguards are acceptance work, not public trading strategy disclosure.

Future optimization: compact tick/side/event columns, lossless ID dictionaries, batch/vectorized read paths, reproducible session checkpoints, and bounded parallel worker scheduling. No full training implementation is authorized by this closeout.
